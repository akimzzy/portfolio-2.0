# Cabinet Grotesk

Cabinet Grotesk is the portfolio's single UI and reading typeface, used for headings, navigation, and body copy. Technical code samples retain the native monospace stack.

The original variable WOFF2 file (100–900) was copied unchanged from the owner's Alluring Aura Scent project, along with its Fontshare license. It is served locally through `next/font/local`; no Google Fonts request is needed. The semantic `--font-portfolio-sans` variable maps into Tailwind's `font-sans` utility.
